Let's keep this simple.

**Free Plan.** Limited messages. Access to Sonnet (fast model). Good for trying Claude out. **Cannot use Claude Code.**

**Pro ($20/month).** 5x more messages. Access to Opus (most powerful model). Extended thinking. Claude Code access. **This is the minimum for this course.**

**Max ($100/month).** Significantly higher limits. Priority access. Best for heavy daily users who run Claude Code all day.

**Team ($30/user/month).** Everything in Pro plus shared workspace, admin controls, and your data is never used for training.

### My Recommendation

**Start with Pro.** It's $20/month and gives you everything you need for this course.

If you find yourself hitting usage limits regularly (Claude will tell you when you're close), upgrade to Max.

Don't overthink this. Pick Pro. Let's move.
