Create `~/.claude/skills/review/SKILL.md`:

```markdown
---
name: review
description: "Review code changes for bugs, security, and improvements"
---

Review all changes since last commit. For each issue:
- **Severity:** Critical / Warning / Info
- **File:** path:line
- **Issue:** What's wrong
- **Fix:** How to fix it
```

Now type `/review` in any session. Done.
