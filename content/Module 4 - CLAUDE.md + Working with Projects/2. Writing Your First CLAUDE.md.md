Create a file called `CLAUDE.md` in the root of your project:

```markdown
# [Project Name]

## Overview
[What is this and what does it do?]

## Tech Stack
- Framework: [e.g., Next.js 15]
- Language: [e.g., TypeScript]
- Styling: [e.g., Tailwind CSS]

## Commands
- `npm run dev` — Start dev server
- `npm run build` — Build for production

## Conventions
- [Your coding style rules]
- [Naming conventions]

## Rules
- [Things Claude should NEVER do]
- [Things Claude should ALWAYS do]
```

### Pro Tip

Ask Claude to write it for you:

*"Look at this project and create a CLAUDE.md that captures the tech stack, structure, and conventions."*

Claude analyzes your project and generates it automatically.
