### The @ Symbol

Reference files directly:

*"Look at @src/components/Header.tsx and add a mobile menu"*

*"Look at @design-mockup.png and build a component that matches this"*

### Best Practices

1. Be specific about paths
2. Tell Claude what to do with the file
3. One task at a time
4. Review before approving
