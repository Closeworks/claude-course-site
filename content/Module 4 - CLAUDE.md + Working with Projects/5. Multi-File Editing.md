Claude can edit your entire project in one operation.

*"Rename 'userData' to 'customerProfile' across the entire project"*

*"Add dark mode to the entire application"*

*"Move all API routes from /pages/api/ to /app/api/ and update imports"*

### Safety Protocol

1. **Commit before** with `git commit -m "before refactor"`
2. **Review the diff** with `git diff`
3. **Test** by running the app
4. **Undo if needed** with `git checkout -- .`

## Action Step

1. Perform a multi-file operation. Review, test, commit or undo.
2. Mark this lesson as **DONE**.
