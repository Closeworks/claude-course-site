This takes 10-15 minutes. Let's go.

### Step 1: Install Node.js

Go to **nodejs.org** and download the LTS version. Run the installer.

Open your terminal and verify:

```
node --version
```

You should see `v20.x.x` or higher. If you see a version number, you're good.

### Step 2: Install Claude Code

In your terminal, run:

```
npm install -g @anthropic-ai/claude-code
```

Wait for it to finish.

### Step 3: Launch It

Navigate to any folder and type:

```
claude
```

First time? It'll open a browser window to log in with your Anthropic account. Follow the prompts.

### Step 4: Test It

Once you're in, type:

```
What files are in this directory?
```

If Claude lists your files, you're in. Welcome to the future.

### Troubleshooting

- **"command not found"** Make sure Node.js installed correctly. Try `npx @anthropic-ai/claude-code` instead.
- **Auth issues** Make sure you're using the account with a Pro or Max subscription.
- **Permission errors on Mac/Linux** Try `sudo npm install -g @anthropic-ai/claude-code`
