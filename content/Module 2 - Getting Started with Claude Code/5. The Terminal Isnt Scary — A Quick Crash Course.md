If you've never used the terminal, this lesson removes the fear.

The terminal is just a text-based way to talk to your computer. Instead of clicking folders, you type commands. That's literally it.

### Where to Find It

- **Mac:** Open the "Terminal" app
- **Windows:** Use "PowerShell" or "Windows Terminal"
- **Linux:** You already know

### The Only Commands You Need

```
pwd              → "Where am I right now?"
ls               → "What's in this folder?"
cd foldername    → "Go into this folder"
cd ..            → "Go back one folder"
mkdir name       → "Create a new folder"
clear            → "Clean up the screen"
```

### Here's the Good News

You don't need to master the terminal. You need exactly 3 things:

1. **Open your terminal**
2. **Navigate to a project folder** (`cd`)
3. **Type `claude`**

Claude handles the rest. Seriously. It runs all the commands for you. You just need to get to the right folder and launch it.

## Action Step

1. Open your terminal and navigate around your computer using the commands above.
2. Create a folder called `claude-projects` on your Desktop, we'll use it for the rest of this course.
3. Mark this lesson as **DONE**.
