Before we go deeper, you need a safety net.

**Git is an unlimited undo button for your entire project.**

Every time you save a snapshot (called a "commit"), you can always go back to that exact state. This means you can let Claude go wild, if it breaks something, you just rewind.

### The 7 Commands You Need

```
git init              → Start tracking a project
git status            → See what changed
git add .             → Stage all changes
git commit -m "msg"   → Save a snapshot
git log               → See your history
git diff              → See exactly what changed
git checkout -- .     → UNDO all uncommitted changes
```

That last one is your panic button. If Claude makes a mess, `git checkout -- .` takes you back to your last commit.

### The Workflow

1. Tell Claude to build something
2. Review what it created
3. **Like it?** `git add .` then `git commit -m "Added feature X"`
4. **Don't like it?** `git checkout -- .` to undo everything
5. Repeat

### Pro Tip

Claude Code understands Git natively. You can say:

- *"Commit everything with the message 'initial setup'"*
- *"Show me what changed since the last commit"*
- *"Undo the last change you made"*

You don't even need to type the commands yourself.

## Action Step

1. Create a new folder, run `git init`, and make your first commit.
2. Practice the cycle: build something, commit, build something else, undo it.
3. Mark this lesson as **DONE**.
