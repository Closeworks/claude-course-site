Claude Code is installed. Let's actually use it.

### Exercise 1: Create a file

```
Create a file called hello.txt that says "I'm learning Claude Code and I'm about to become dangerous."
```

Claude creates the file. You'll see it appear in your folder.

### Exercise 2: Ask about your system

```
What operating system am I running? How much disk space do I have?
```

Claude runs actual terminal commands to find out. It's not guessing, it's checking.

### Exercise 3: Build something

```
Create a simple HTML page with a dark theme that says "Built with Claude Code" in the center. Make it look modern and clean.
```

Open the file in your browser. You just built a webpage without writing a single line of code.

### Understanding Permissions

Claude asks before doing things:
- **Reading files** Usually auto-approved
- **Creating/editing files** May ask for confirmation
- **Running commands** Will ask for confirmation

You'll see prompts like *"Allow Claude to create file X?"*, press **Y** to approve, **N** to deny.

You're always in control.

### Key Shortcuts

- `Enter` Send message
- `Escape` Cancel current action
- `Ctrl+C` Stop Claude mid-response
- `/help` See all commands
- `/clear` Start fresh
