Here's the difference between Claude.ai and Claude Code in one sentence:

**Claude.ai is a chatbot. Claude Code is an AI agent.**

On claude.ai, you type and Claude responds. That's it. It can't touch your files. It can't run code. It can't install anything.

Claude Code lives in your terminal. It can:

- **Read and write any file** on your computer
- **Run terminal commands**, install packages, start servers, run scripts
- **Build entire applications**, frontend, backend, database, everything
- **Use Git** for version control (your undo button)
- **Connect to external tools**, GitHub, Slack, databases, Obsidian, Instagram
- **Launch multiple AI agents** working in parallel
- **Remember your project** between sessions

Think of it this way: Claude.ai is like texting a smart friend for advice. Claude Code is like having that friend sit down at your computer and actually do the work.

And the wildest part?

**You don't need to know how to code.** You describe what you want. Claude builds it.

That's what we're setting up in this module.
