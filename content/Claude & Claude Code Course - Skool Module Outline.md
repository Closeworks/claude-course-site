## Skool Setup Notes

### Classroom Settings
- **Course name:** Claude & Claude Code (Zero to Dangerous)
- **Drip content:** Modules 1-3 unlocked immediately, Modules 4+ drip weekly (or unlock all at once for higher tiers)
- **Completion tracking:** ON (green checkmarks show progress)
- **Each module header** = collapsible section in Skool

### Formatting in Skool
- Module headers use: `MODULE X: Title — Subtitle`
- Lesson titles are clean and scannable (no jargon)
- Each lesson has a short description shown as subtitle text
- Videos are primary content, text lessons supplement

### Recommended Lesson Flow (per lesson)
1. **Video** (5-15 min) — teaching the concept
2. **Action step** — what to do right now
3. **Resource links** — relevant docs, templates, downloads
4. **Discussion prompt** — question to post in the community
